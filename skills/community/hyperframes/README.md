# HyperFrames skills snapshot

This directory contains the complete `skills/` tree from [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes), pinned to the commit recorded in [`registry/sources.json`](../../registry/sources.json).

The application source is intentionally not vendored. This library preserves all twenty agent skill bundles, their references, and required assets while keeping the collection focused on reusable agent behavior.

Start with [`skills/hyperframes/SKILL.md`](skills/hyperframes/SKILL.md), which routes requests to the appropriate workflow and domain skills.
