## Evaluate a new skill

Read [Contributing](CONTRIBUTING.md), then ask:

1. Does it have a narrow, legible trigger?
2. Does it change agent behavior rather than restate generic advice?
3. Does it define a repeatable workflow with decision points?
4. Does it specify verification or acceptance criteria?
5. Can it be demonstrated without exposing sensitive context?
6. Is its license and provenance clear?
